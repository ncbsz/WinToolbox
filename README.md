# WinToolbox 更新日志

作者 by：xixidan ｜ GitHub：<https://github.com/ncbsz/WinToolbox>

## v1.3

**新增**

- **关闭弹窗三选一**：最小化到托盘 / 直接退出 / 取消（点 ×、Esc、取消都不关闭）；可勾「记住」不再询问，设置页提供「每次询问 / 最小化到托盘 / 直接退出」三选一
- **最小化或收托盘时真暂停性能监测**：页面 1 秒轮询 + 服务端温度/GPU/网络采样线程全部静默，恢复后自动继续；进程亲和性、内存/IO 优先级、电源计划等即写即生效的设置不受影响
- **DNS 测速改 ICMP ping 口径**（对齐 DnsTools），逐条实时显示，新增「本机 DNS」通信延迟模式（ping 通率从 31→75/123）
- **右键「定位文件夹 / 复制路径」**覆盖全部列表，取不到路径的项自动置灰
- **软件管理对齐 Geek**：右键卸载/强制删条目/更新补丁视图/架构列/列表缓存；卸载逻辑重做（按规则解析命令行、MSI 走 msiexec、等卸载真正结束再扫残留）
- **CPU 调试新增「调度增强」**：自定义核绑定+强亲和、内存/IO 优先级、释放工作集
- **显卡伪装独立成大类**：30 款预设（RTX 50/40/30、GTX、AMD、Intel），大号预览块，只改显示名不改硬件能力
- **电源计划**：高性能/卓越性能模板 + 导入 .pow（自动扫描本机文件并回读验证）
- **优化项 +4（共 85 条）**；设置页主题色改「色块 + 色相条」
- **整机「扫描卸载残留」**：孤儿卸载项/启动项/服务、失效快捷方式、疑似残留目录（多来源认领，低置信默认不勾选）
- **CPU 温度改 PDH 直读**（1ms，多热区取最高 + 中位/EMA 滤波，稳态 ±0.5℃）

**修复**

- **数据会话缓存**：切页/排序/搜索不再反复查系统，子进程 24→2
- **老电脑启动卡顿**：缓存击穿加单飞锁、失败退避、最小化后停止轮询
- **运行时长超 24.8 天读不出**：`GetTickCount64` 显式设 `restype`
- **启动权限**：manifest 改 `requireAdministrator`，`admin_mode` 以实际提权为准，UAC 被拒不退出
- **DNS 并行探测静默退化串行**：任务结构错配 → 修后 36.5s→18.6s
- **「定位文件夹」路径含空格打不开**：改用 Shell API `SHOpenFolderAndSelectItems`
- **残留清理「扫得到删不掉」**：单元格 `UserRole` 传结构 + 按类别精确校验安全闸
- 温度读数跳变/刷新不及时（PowerShell 1.8s → PDH 1ms）

## v1.2

- CPU 调试进程表新增 CPU/GPU 占用列
- 外观对齐 Win11 原生；补全交互态

**修复**

- 高分辨率/高缩放屏兼容重做（150%/175% 文字被裁 → PassThrough）
- 关闭软件瞬间后台刷新回调偶发报错

**新增**

## 说明

打开软件不会修改任何系统设置，所有项默认不勾选，手动勾选并确认后才会应用，写入前自动备份、可撤销。
