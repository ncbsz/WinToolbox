# WinToolbox v1.1 更新日志

作者 by：xixidan ｜ GitHub：<https://github.com/ncbsz/WinToolbox>

## 新增

1. **系统优化规则库扩容**：34 条 → **81 条**，分类 7 → **12 组**，对齐 Windows「设置」与「控制面板」分区（系统 / 个性化 / 隐私和安全性 / 安全防护 / 网络和 Internet / Windows 更新 / 游戏 / 应用 / 资源管理器 / 输入与键盘 / 性能优化 / Edge）
2. **新增「CPU 调试」页**：
   - 大小核识别（P 核 / E 核，`GetLogicalProcessorInformationEx` 读 EfficiencyClass）
   - 每逻辑处理器实时占用 + 实时频率，逐核显示
   - 电源计划切换；**按所选计划读取**处理器最小/最大状态、EPP 能效偏好（不切错计划）
   - 进程核心亲和：一键绑定到 P 核 / E 核 / 全核
   - E-core 全局开关（`bcdedit numproc`，需重启，可一键恢复）
3. **DNS 检测新增 IPv6 模式**（16 条 IPv6 公共 DNS），模式共四种：国内 / 国外 / 混合 / IPv6
4. **DNS 测试改为并行探测**：121 个 DNS 约 6 秒出全量结果（原先串行需一分多钟）
5. **软件管理**：列表显示每个程序的图标；支持按**名称 / 大小 / 安装日期**排序（升降序）
6. **卸载后残留扫描**：卸载程序执行完弹窗询问，列出残留**文件与注册表项**并逐项勾选删除（含白名单安全限制）
7. **垃圾清理标注建议等级与用途**：11 类项目标注 🟢建议清理 / 🔵可以清理 / 🟠谨慎清理，并新增「说明」列写明这些文件是什么、删了会怎样
8. **全列表支持点击表头排序**（含数值列按大小排序：「9 MB」不再排在「1 GB」前面）
9. **概览 GPU 详情**：支持列出并选择电脑里**所有显卡**（PDH「GPU Engine」+ DirectX 注册表 LUID 映射，Intel/AMD/NVIDIA 通用），每条进度条右侧显示具体百分比
10. **持续 Ping 延迟明细**：逐条记录每次延迟（新结果在最上，向下为历史），不再只有汇总值
11. **策略诊断**：改为手动点击扫描；清理前弹确认框并说明备份位置，清理时自动把每项导出成 `.reg` 备份，结果提示备份文件数量与路径
12. **设置页「关于」**：显示作者 by：xixidan 与 GitHub 地址，并提供「打开 GitHub 项目主页」按钮
13. **启动固定显示概览页**（不再恢复上次停留的页面）

## 修复

1. **打包版启动即崩溃**（`No module named 'email'`）：打包配置误将 `email` 模块排除，而 `http.server` 依赖它 —— 已移出排除清单
2. **“打开软件就自动改系统设置”的误导**：原逻辑会把「当前值恰好等于优化目标」的项自动勾选并提示“已检测 N 项”，且勾选会持久化，下次误点应用会覆盖用户自己的设置 —— 已改为**只读检测**：不自动勾选、不记忆勾选、每次打开全部不勾选
3. **DNS 延迟不准**：原用热门域名查询，被运营商缓存/透明拦截秒回，显示假延迟（常见 2ms）—— 改为**随机子域名强制真实递归**，预热后多次取样取最小值
4. **策略诊断/垃圾清理“列不出来”**：可排序表格与逐行插入冲突，导致「12 处残留」只显示 1 行、其余为空白行 —— 填表期间关闭排序、填完恢复
5. **勾选与数据错位**：列表排序后按行号取数据会点错项 —— 改为把路径/ID 绑定在每一行上
6. **扫描慢**：垃圾清理原为串行统计各目录体积 —— 改为每项独立后台任务并行统计，扫描期间显示进度条与百分比（n/11），**扫完再一次性列出**
7. **概览页每秒闪烁**：GPU / 磁盘 / 网络卡片原先每秒销毁重建控件，且样式每秒无条件重刷 —— 改为控件复用、仅在颜色档位变化时重刷样式
8. **数字输入框上箭头点击无效**：输入框被样式表接管后原生按钮热区失效 —— 显式定义上/下按钮与箭头
9. **勾选框只剩一个“✓”没有方框**：全局样式接管后原生指示器不再画框 —— 自绘指示器（空框 / 悬停蓝框 / 蓝底白勾），表格内勾选一并修复
10. **垃圾清理进入页面即自动扫描** —— 改为手动点击「开始扫描」；策略诊断同步改为手动

## 说明

- 软件**打开时不会修改任何系统设置**（只读检测），所有项默认不勾选，需手动勾选并在安全确认弹窗中确认后才会应用；写入前自动备份原值，可「撤销上次优化」或「还原所选」
- 写 `SOFTWARE\Policies` 的项标记【策略】并默认不勾选
- 不提供 CPU 电压/功耗墙解锁（MSR 直写需内核驱动，杀软易误报且有风险）
