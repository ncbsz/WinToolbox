# WinToolbox 更新日志

作者 by：xixidan ｜ GitHub：<https://github.com/ncbsz/WinToolbox>

## v1.2

**新增**

- **界面主题色可调**：设置 → 外观，8 个常用色块 + 「自定义颜色…」调色盘任选，默认**跟随 Windows 强调色**。按钮、选中行、开关、进度条、导航高亮、通知卡边框全部跟随；CPU / 内存 / GPU 等性能曲线仍各自用独立颜色
- **主指标条显示具体信息**：处理器显示型号简称 · 核线程 · 基准频率 · 温度，显卡**优先显示独显**（无独显时显示占用最高的卡）· 温度，网络显示网卡名 · 协商速率（完整名称放悬停提示）
- **CPU 调试页进程表新增 CPU / GPU 占用列**：按数值排序，任务管理器口径；GPU 占用由常驻采样线程实时喂养（原先进程表只有内存列）
- **外观对齐 Win11 原生**：改为层底色 —— 浅色 #F3F3F3 底 + 白卡片，深色 #202020 底 + #2B2B2B 卡片；卡片与控件圆角、控件底边、导航选中态按 Win11 规范重做
- 交互态补全：按钮悬停/按下、输入框聚焦、表头悬停均跟随主题色

**修复**

- **高分辨率 / 高缩放屏兼容性重做**（150%/175% 文字被裁、2K 屏画面过大）：
  DPI 舍入策略改为按真实缩放渲染（PassThrough）；窗口逻辑尺寸与字号不再重复乘系统缩放
  —— 2K+150% 下窗口占屏从 86% 回落到 69%，与 100% 屏视觉一致，字号符合系统标准
- 关闭软件瞬间，后台残留的刷新回调偶发报错（现静默丢弃）

## v1.1

**新增**

- 系统优化规则库扩到 **81 条 / 12 个分类**（对齐 Windows 设置与控制面板分区）
- 新增 **CPU 调试**页：大小核调度、每核实时频率与占用、电源计划参数、进程绑核、E-core 开关
- DNS 检测新增 **IPv6 模式**，改为并行探测（121 个 DNS 约 6 秒出结果）
- 软件管理：显示图标、可按名称/大小/安装日期排序、**卸载后残留扫描**（文件 + 注册表）
- 垃圾清理：标注**建议清理 / 可以清理 / 谨慎清理**及用途说明，并行扫描带进度百分比
- 所有列表支持**点击表头排序**；GPU 详情可切换电脑里**所有显卡**并显示具体百分比
- 持续 Ping 增加逐条延迟明细；策略诊断改为手动扫描（清理前自动备份 `.reg`）
- 关于页显示作者与 GitHub；启动固定显示概览页

**修复**

- 打包版启动崩溃（`No module named 'email'`）
- 打开软件自动勾选、可能覆盖自己设置 → 改为只读检测，默认全不勾选
- DNS 延迟不准（热门域名被运营商缓存导致假 2ms）→ 改用随机子域名测真实延迟
- 列表空行、排序后勾选错位
- 垃圾 / 策略扫描慢、进入页面自动扫描
- 概览页每秒闪烁、输入框上箭头点不动、勾选框没有方框

## 说明

打开软件不会修改任何系统设置，所有项默认不勾选，手动勾选并确认后才会应用，写入前自动备份、可撤销。
